# Contributing to DigitMoney OS

Thank you for your interest in contributing to DigitMoney OS.

We welcome high-quality contributions that improve the skill, documentation, or overall usefulness of the project.

## Ways to Contribute

- Improve the core `SKILL.md`
- Enhance or expand files in `references/`
- Improve documentation in `docs/`
- Fix typos, clarity, or structure issues
- Suggest new capabilities or better decision frameworks
- Report bugs or unclear behavior

## Getting Started

1. Fork the repository
2. Create a new branch from `main`
3. Make your changes
4. Test that the skill still works as expected when installed
5. Open a Pull Request with a clear description of what you changed and why

## Guidelines

- Keep the tone consistent with the existing skill (calm, precise, capital-preservation first)
- Prefer clarity over complexity
- Do not introduce unnecessary dependencies
- When changing decision logic or risk rules, explain the reasoning clearly in the PR
- Documentation changes should be accurate and up-to-date with the skill behavior

## Pull Request Process

1. Ensure your PR has a clear title and description
2. Reference any related issues if applicable
3. Keep changes focused — one logical change per PR is preferred
4. Be open to feedback and iteration

## Code of Conduct

Be respectful, constructive, and professional.  
We aim to maintain a high-signal, low-ego environment focused on building something genuinely useful.

## Questions?

Feel free to open an issue or reach out via [X/Twitter](https://x.com/digitmoneybot).

Thank you for helping improve DigitMoney OS.
