## What is DigitMoney OS?

DigitMoney OS is a highly capable personal financial agent built for the Bankr ecosystem.

It acts as your on-chain CFO — protecting capital, optimizing yield, routing money across chains, and enforcing your personal financial rules through natural language.

**Advanced under the hood. Extremely simple to use.**

---

## Key Capabilities

| Module | What it does |
| --- | --- |
| **Smart Portfolio Engine** | Intelligent allocation & rebalancing across risk regimes |
| **Yield Engine** | Risk-adjusted yield maximization + auto-compounding |
| **Money Router** | Best-execution cross-chain transfers & payments |
| **Cashflow & Rule Engine** | Natural language financial rules that persist |
| **Risk Guard** | Drawdown protection, Safe Mode, and position sizing |
| **Memory Layer** | Remembers your goals, risk tolerance, and preferences |

---

## Quick Start

Install the skill in any compatible agent (Bankr, OpenClaw, Claude Code, etc.):

```text
install the digitmoney-os skill from https://github.com/digitmoneybot/digitmoney-os
```

Then start talking to it:

```text
Manage my portfolio with a balanced risk profile
Maximize risk-adjusted yield on my stablecoins
Create a rule: when weekly profit exceeds $500, allocate 40% to the best current yield
Activate defensive mode
Show my current capital allocation and recommendations
```
